# 机械臂动作说明

## 动作列表

| 动作名称 | 动作描述 | CAN接口 |
|---------|---------|--------|
| Lax | 左臂比爱心 | can0 (左臂) |
| Rax | 右臂比爱心 | can1 (右臂) |
| Rhs | 右臂挥手 | can1 (右臂) |
| Rhs_big | 右臂大挥手 | can1 (右臂) |
| Rpb | 右臂跑步 | can1 (右臂) |
| Lpb | 左臂跑步 | can0 (左臂) |

> **注意**：使用时请确保动作与CAN接口正确对应（L=左臂使用can0，R=右臂使用can1）

---

## 脚本功能说明

### 1. action_interactive.sh

**功能**：动作录制与数据转换工具

**使用流程**：
1. 启动脚本后，先配置CAN接口
2. 选择"启动CAN数据帧监听"开始录制（选择监听从臂的数据）
3. 执行摇操作机械臂进行动作录制
4. 停止监听后，选择"转换日志为可发送格式"
5. 生成的转换文件可用于 `send_data` 发送

**主要功能**：
- CAN接口配置
- 数据帧监听（仅监听00x ID）
- 日志格式转换

---

### 2. send_data

**功能**：动作数据发送工具

**使用流程**：
1. 确保机械臂处于**垂直零位**（初始位置）
2. 运行可执行文件 `./send_data`
3. 选择单文件或双文件发送模式
4. 输入日志文件路径和目标CAN接口
5. 按 Ctrl+C 停止发送

**发送策略**：
- 前6000帧：1kHz 频率发送（用于电机初始化）
- 6000帧后：5kHz 频率发送（正常控制）

---

## 注意事项

1. **初始位置**：发送动作前务必确保机械臂处于垂直零位
2. **CAN接口**：左臂使用 can0，右臂使用 can1，请勿混淆
3. **安全提示**：运行动作前请确保工作区域安全，避免碰撞
4. **录制提示**：录制时请选择监听从臂（跟随臂）的数据
5. **文件格式**：发送前需先使用 `action_interactive.sh` 转换日志格式
